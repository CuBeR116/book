# Имя, которого быть не должно

Тёмное фэнтези: книга и манхва. Репозиторий хранит **только тексты**.
Иллюстрации, концепты, `.kra` и Blender-файлы живут в Яндекс.Диске и в git не попадают.

| `Манхва/Книга/ЭМЕРИН — канон.md` | канон центрального персонажа, главный источник правды |

## Правила работы

- Загруженные файлы — канон. Если идея ломает канон, скажи прямо, какой файл и место она ломает.
- Голоса персонажей держим по `ЭМЕРИН — голос.md` и `Голоса_POV.md`.
- Магия имеет цену: любой новый приём проверяй по `Система магии/Затраты энергии/`.
- Развитие сюжета предлагай вариантами (2–3 с разными последствиями), а не одним «правильным».
- Не выдумывай факты мира, которых нет в файлах: спроси или явно пометь «моя догадка».
- Не переписывай готовые главы без прямой просьбы.
- Отвечай по-русски, сначала коротко по сути.
- `_архив/` читай только когда просят: там устаревшие версии.

## Git — всё только в `main`

Работаем в одной ветке — `main`, с любого устройства. Отдельных веток не создаём:
они не доезжают до другого устройства и расходятся с основным текстом.

- **Перед любой правкой** — `git checkout main && git pull`. Если сессия стартовала
  на ветке `claude/*` или любой другой — всё равно переключись на `main` и работай там.
- **После правки** — коммит и `git push origin main`. Сообщение коротко и по-русски,
  например `идеи: развилка с Велайной в гл. 12`.
- Если пуш отклонён (с другого устройства успели запушить) — `git pull --rebase`,
  потом снова `git push`. При конфликте в главе не выбирай молча: покажи обе версии и спроси.

## Работа с телефона

Сессия с телефона — это **обсуждение идей**, а не переписывание глав.

Что делать с телефона:
- ловить идеи → дописывать в конец `Манхва/Книга/ИДЕИ.md` с датой;
- находить нестыковки → записывать в `ПРОХОД — дыры и логика.md`;
- обсуждать, спорить, проверять по канону — сколько угодно, без правок файлов.

**После любой правки файлов — коммит и пуш в `main`** (см. «Git — всё только в `main`»),
иначе изменения не доедут до компьютера.

За компьютером: `git pull`, затем «разбери идеи» — раскидать накопленное по канону, главам и долгам.
