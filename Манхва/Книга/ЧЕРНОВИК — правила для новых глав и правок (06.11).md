# ЧЕРНОВИК — что учитывать сразу, при генерации новых глав и при правке (06.11.2026)

Итог двух дней 05–06.11: пять проходов по гл. 1–6, пять слепых вердиктов (Fable ×4, Opus, Argon ×3), пилот
агентов. Всё, что ниже, должно стоять в черновике новой главы с первого прогона, а не вычищаться потом по пять
раз. Относится и к модели, и к авторской правке. Источники: «ЭМЕРИН — голос», «ПРОВЕРКА — следы нейросети»,
«ПРАВИЛА — пишу сам», «проход на шероховатость 06.11 — метод и регистры», «ПЕРСОНАЖИ — состояние и следующий шаг».

## 1. Голос: грамматика следит за волей

- Волевой поступок — глагол мужского рода без подлежащего: «Оперся ладонью о колено, вытолкнул себя вверх»,
  «Пошел следом», «Сел и открыл книгу», «Лег». «Он» нет. Имя в повествовании — нет до точки присвоения (решено
  06.11); только в чужих репликах.
- Тело само, без решения — часть тела как подлежащее («Ноги стояли», «Ноги понесли»); редко.
- Случилось с телом — безличное («Ударило в метку», «Сморило», «Не спалось»).
- План — инфинитив («Найти мышцы. Потянуть»). Результат — страдательный («Все съедено»). Мир на тело («Свет
  резанул по глазам»). Чужая реакция («Линея отшатнулась»). Обобщённое «стоишь / держишь» — для привычного.
- Ротация: не больше двух одинаковых ходов подряд. Цепочка без подлежащего принадлежит последнему названному —
  после «Кайрен пошёл…» нельзя «и пошёл за ним».
- «Пришлось», «сам/сама», «оставалось + инфинитив», «было нечем», «хватило» — по одному-два на главу, не каркас.

## 2. Ритм: диапазон, а не метроном

- Длина фразы идёт за состоянием сцены: покой (книга, дорога, ночь) — длинный период на «пока / когда / потому
  что»; кризис — ломается фраза, не голова (начало фразы, тело перебивает, голова подхватывает с другого места);
  холодный метод (расправа, арена) — ровно, нарочно.
- В абзаце из 4+ фраз — хотя бы одна на 25–40 слов и хотя бы три разных хода.
- Отбивки в одну строку — 6–8 на главу, только на пике; остальное вливать в **следующий** абзац.
- Замок-афоризм — не в каждом абзаце; каждый третий абзац кончается деталью или обрывается. Тест вычёркивания.
- Концовка главы — не обязательно удар; одна из трёх может кончиться бытом.
- Тире 30–60 на 10 тыс. знаков (у Чехова 38–54), двоеточий ≤10, «не X, а Y» ≤5, «ни…, ни…» — редко, триады ≤1.

## 3. Что судьи ловят всегда (квоты на главу)

| примета | квота |
|---|---|
| однословные абзацы-удары | 6–8, на пике |
| афоризм в конце абзаца | не чаще каждого третьего абзаца |
| «так делают, когда…» / «как + глагол 3 л.» | 1; остальные сравнения — существительным, творительным, ярлыком |
| «Значит / Выходит / Отсюда выходило» | ≤4 |
| «было нечем», «оставалось + инф.», «хватило» | ≤1 каждого |
| «X, которого не было» | ≤1 на книгу |
| каталог запахов «пришёл — перечислил 4–5 — пошёл» | только новая локация, ≤3 запаха, лучше один точный |
| «будто / словно» | ≤3,5 на 10 тыс.; объясняющие — снимать |
| «коротко», «кивнул», «разом», «раньше, чем [мысль]» | ≤2 каждого |
| «соль», «вручную», «три шага», «посох к груди», «прядь», «плечи к ушам» | раз на главу, когда это новость; лейтмотив растёт или молчит |
| еда, маршрут, повторная рутина | 1-й раз подробно, 2-й — что изменилось, 3-й — три слова |
| «что-то / кто-то» | ≤2,5 на 10 тыс. (в 1.3 — больше, это пустота) |

## 4. Объяснять или показывать

- Назвать вещь в первый раз — да («Целитель.», «Яйца.»). Пересказать показанное выводом — нет.
- Правило автора про сонного читателя: убирая вывод, назвать вещь своим именем в сцене. Где вывод несёт решение
  героя — перефразировать коротко и прямо, не вычёркивать.
- Ошибка героя (неверное истолкование) — ценность, не трогать.
- Одна некрасивая живая фраза на страницу — не выглаживать. Одно сравнение, которое не попало, — оставить.
- Одну ступеньку мысли пропустить; на одной нелогичной яркой детали задержаться. Это единственное, что отличает
  от модели по всем пяти вердиктам, и это делает только автор.

## 5. Люди, кроме Эмерина

- До черновика — таблица состояния на каждого в сцене: что видел минуту назад, что в руках, кому подчинён, чего
  хочет и боится прямо сейчас, что сделает руками, что скажет, что заметит в нём Эмерин **кроме страха**.
- Сцена с двумя и больше — проигрывать агентами (ПЕРСОНАЖИ, раздел «как агентов»): реплики по очереди, реакции
  параллельно, цена должна бить по тому, чего персонаж хочет сейчас. На выходе протокол, проза — автор.
- Палитра сигналов шире страха: походка, как ест, что делает руками, ритм чужой речи без смысла, юмор, который
  герой фиксирует, не понимая. Узость взгляда героя — канон; ширина того, что он видит, — нет.

## 6. Что судьи считают человеческим — производить нарочно

Дальние связки через главы (облака, печенье, «Ээ-р» → Эрейн, ладонь плашмя); правило перевода слов по мере
выучивания; находки из логики мира (подошва, след, перо без чернил); типографика на пиках (счёт, «открыто
закрыто», обрыв на «а тут»); свои идиолектные зачины («А…», «И…»); «не объясняет» — два «на колени», следы.

## 7. Конвейер одной главы (чтобы не три месяца на шесть глав)

1. План сцены (ПЛАН — гл. N) + ставка главы: один вопрос с ценой.
2. Таблица состояния персонажей; для сцен с двумя и больше — агенты, протокол.
3. Черновик по этому файлу с первого прогона; сразу скрипт `python -X utf8 -I Манхва/Книга/_служебное/проверить_следы.py`.
4. Авторский проход один раз, своей рукой: неровность, пропущенная ступенька, деталь без причины, концовка бытом.
5. Два слепых судьи параллельно — только если есть сомнение; один прогон не измерение.
6. Выкладка. Не возвращаться к главе пять раз: ровность растёт с каждым проходом.
