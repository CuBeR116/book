Как работает магия
## 1. **Язык магии (Магические круги)**

- Абсолютно другая структура:
    - Не алфавит.
    - Наборы знаков, похожих на **геометрические формулы**, **матрицы**, **механические узоры**.
- **Каждый слот круга — это отдельный параметр**, который требует конкретного заполнения.
- Магия устроена **по строгой логике**, но в мире её используют ритуально и не понимают сути.

# Основная механика магии:

- Базовые круги имеют 3, 5, 7 слотов.
- Если параметры не нужны, жители всё равно их "заполняют" лишней ментальной (Этером) энергией.
- Чем больше кругов — тем дороже магия:
    - Формула расхода маны → **2.5ⁿ**, где _n_ — количество кругов.
- Каждый узел потребляет 1.2**ⁿ** , где _n_ - количество узлов в круге
- Герой **Эмерин** поймёт, что многие параметры можно опустить, оптимизировать магию.

# Базовые стихии мира:

Для расчёта логики магических кругов нужны фундаментальные категории стихий.

| Базовая стихия | Связано с                   | Примечание                                                                      |
| -------------- | --------------------------- | ------------------------------------------------------------------------------- |
| **Вода**       | Жидкости, потоки            | Чистая стихия для роста, массы                                                  |
| **Огонь**      | Температура, энергия        | Отопление, уничтожение, ускорение                                               |
| **Земля**      | Материя, форма              | Твёрдые объекты, строительство                                                  |
| **Воздух**     | Движение, давление          | Скорость, перенос                                                               |
| **Эфир**       | Связь, магические структуры | Необходим для работы сложной магии, используется для удержания остальных стихий |

**Эфир**— это **структурная основа** магических явлений.

Он не создаёт материю (как Земля, Вода, Огонь, Воздух), а **связывает** её, **удерживает** форму, **стабилизирует** процессы.

|Параметр|За что отвечает Эфир|
|---|---|
|Удержание формы|Чтобы водяной шар не распадался в капли.|
|Поддержание структуры|Чтобы магический объект (огненная стрела, ледяная глыба) не рассыпался сразу.|
|Продление существования|Чем выше концентрация Эфира, тем дольше магия «жива» без подпитки.|
|Магическая сцепка стихий|Чтобы разные стихии (например, Вода + Огонь) не уничтожали друг друга.|
|Канализация силы|Чтобы заклинание шло по нужному пути, а не рассыпалось в пространстве.|
